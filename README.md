# Hawkins Education

Сайт школы, админ-панель и кабинет учителя.

| Адрес | Что там |
|---|---|
| `/` | Продающий лендинг: 3D-hero, программы, квиз-подбор, тарифы, FAQ, форма заявки, WhatsApp |
| `/portal` | Вход для администратора и учителей |
| `/portal#/dashboard` | **Админ:** обзор дня, нагрузка учителей, новые заявки |
| `/portal#/schedule` | **Админ:** расписание (неделя / день по учителям / список), добавление уроков кликом по сетке, повтор по неделям, проверка пересечений по учителю и кабинету |
| `/portal#/teachers` | **Админ:** учителя, логины/PIN, цвет в расписании |
| `/portal#/leads` | **Админ:** заявки с сайта (воронка, статусы, звонок / WhatsApp в один клик) |
| `/portal#/my` | **Учитель:** мой день, ближайшие уроки, отметка «Провёл», заметки к урокам |

## Вход

- Администратор: логин `admin`, пароль — переменная окружения `ADMIN_PASSWORD`.
- Учителя: логин и PIN задаёт администратор в разделе «Учителя».
  Демо-учителя (`aigerim`, `daniyar`, `alina`, `erzhan`) имеют PIN `1111` — удалите их или смените PIN.

## Что заменить перед запуском рекламы

1. `public/assets/js/site.js` → блок `CONFIG`: номер WhatsApp, телефон, Instagram.
2. `public/index.html`: цифры (рейтинг, кол-во учеников, результаты), отзывы, преподаватели и цены — сейчас там **примеры**.
3. Домен в `<script type="application/ld+json">` и `og:image`.

## Технологии

- Статический фронтенд без сборки: HTML/CSS/JS, GSAP + ScrollTrigger, Lenis (плавный скролл), Three.js (частицы в hero).
- API: одна serverless-функция Vercel (`api/handler.js`).
- Данные: приватный Vercel Blob (`BLOB_READ_WRITE_TOKEN`); локально — файл `.data/db.json`.
- Сессии: подписанные HttpOnly-cookie (`SESSION_SECRET`), PIN хранятся в виде scrypt-хэшей.

## Переменные окружения (Vercel)

| Переменная | Назначение |
|---|---|
| `ADMIN_PASSWORD` | пароль администратора |
| `SESSION_SECRET` | длинная случайная строка для подписи сессий |
| `BLOB_READ_WRITE_TOKEN` | создаётся автоматически при подключении Blob-хранилища |

## Локальный запуск

```bash
npm install
npm run dev   # http://localhost:3000 , админ: admin / admin
```
